## 一、世系（纳兰氏／叶赫那拉）

### 1.1 墓志铭的说法（主源，B）
徐乾学《墓志铭》原文：「君之先世有葉赫之地，自明初內附中國。諱星懇達爾漢君，始祖也。六傳至諱養汲弩君，高祖考也。有子三人，第三子諱金臺什君，曾祖考也。女弟謂太祖高皇帝後，生太宗文皇帝。太祖高皇帝舉大事，而葉赫為明外捍，數遣使諭，不聽，因加兵，克葉赫，金臺什死焉，卒以舊恩存其世祀。其次子即今太傅公之考，諱倪迓韓君，祖考也。君太傅之長子，母覺羅氏，一品夫人。」【通志堂集_19.md（徐乾學撰）｜B】

按此文画出的世系（照原文，不补）：
```
星懇達爾漢（始祖，有葉赫之地）
  └六傳→ 養汲弩（高祖考），有子三人
        ├第三子 金臺什（曾祖考）；其女弟＝太祖高皇帝后，生太宗文皇帝
        └其次子 倪迓韓（祖考）──〔原文语法可读作养汲弩次子，亦可读作金台什次子，见 1.3〕
              └ 明珠（太傅公／相國）配覺羅氏（一品夫人）
                    ├ 長：性德（初名成德，字容若）
                    └ 又有揆敘、揆方（见 1.8，出他源）
```

### 1.3 两处必须存疑的世系矛盾
1. 「金臺什」与「倪迓韓」是兄弟还是父子：卷19《墓志銘》「有子三人，第三子諱金臺什……其次子即今太傅公之考，諱倪迓韓」读作二人同为养汲弩之子（则曾祖与祖为兄弟，自相矛盾）；同卷《神道碑文》「曾祖考諱金臺什……其次子諱倪迓韓者，則太傅之父」读作倪迓韩为金台什之子。明珠、揆叙、富格、永寿四通碑（「祖諱金太石，考諱倪迓漢」「高祖金台石，曾祖倪雅漢」）皆作父子。语料本身未作裁断，本文只并列。【通志堂集_19.md；皇清誥授…明公墓志銘.md；皇清誥授…揆公墓志銘.md；皇清誥贈…富公神道碑文.md；皇清誥授…永公墓志銘.md｜B／C】
2. 世代起算点各源不同（四傳／五傳／六傳），因各碑以立碑者本人为基准，不可直接互校。

### 1.4 政治叙述的性质（使用时务必带上这一句）
「葉赫為明外捍，數遣使諭，不聽，因加兵，克葉赫，金臺什死焉，卒以舊恩存其世祀」是把叶赫亡国写成「抗拒天命、蒙恩存祀」的清廷官方说法；「女弟作嬪太祖高皇帝，實生太宗文皇帝」「孝慈高皇后為金台石女弟」则是把家族荣耀系于政治联姻。二者均出身为朝廷与相国家写作碑志的人之手（徐乾學、王鴻緒、王頊齡、趙殿最、蔣廷錫），属 B／C 级「官方立场叙述」，不等于史实；「滅扈倫國」「北關」等语同属这一系统。【同上各文件】

### 1.8 兄弟与家族姻娅（皆出碑铭，B／C）
- 揆叙：「次……揆敘」；「年八歲，受業於吳江孝廉吳兆騫」「歲乙丑，公年十二歲，公兄容若先生殤，哭之甚哀」【皇清誥授…揆公墓志銘.md（王頊齡撰）｜B】。其配耿氏（「柔嘉公主所生，駙馬都尉愨敏公愛女」）【皇清誥封一品夫人揆文端公元配永母耿太夫人墓志銘.md｜B】。
- 揆方：「第三子」「字正叔」「尚康親王女郡主」；年羹尧撰其志，自述「餘昔娶公兄納蘭公女，故公於餘情好最篤」；同撰郡主志【皇清誥封和碩額駙納蘭揆公墓志銘.md、皇清冊封郡主覺羅氏墓志銘.md（年羹堯撰、陳奕禧書丹、王鴻緒篆蓋）｜B】。
- 永寿：本揆方子，「文端公無子，聖祖仁皇帝命以公為子」；「公諱永壽，字仁山，別號是觀居士」，揆叙志「嗣子永壽以隧道之碑請餘志而銘之」、明珠志「次永壽，次永福，皆揆方出」同【皇清誥授…永公墓志銘.md:7（蔣廷錫撰）｜C】；又「餘惟先大夫與公伯父成公曩以癸丑同年相友善」（撰者父与成德同年）。**按**：单页《徐志》（重取后足本）以「永壽」为纳兰第二子，与此三源互斥，两说并立待核，见 1.7。
- 性德女婿：明珠志「孫女四人：長適翰林院侍講高其倬，次適翰林院侍講學士年羹堯，次適馬喀納……皆性德出」【皇清誥授…明公墓志銘.md｜B】。
